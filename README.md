# My apprenticeship

This is your workspace for the Code2College apprenticeship. You made it from
the C2C `my-apprenticeship` template.

## Three rules for this repo

1. **This repo is public.** Anyone on the internet can read it.
2. **Never put personal info about you, classmates or real people here.** No
   last names, phone numbers, addresses or passwords. The made up business
   facts in facts files are fine.
3. **Fictional businesses only.** Ridgeline Veterinary Clinic and the other
   clients in this program are made up for practice.

## What is in here

| File | What it is |
|---|---|
| `index.html` | Your portfolio page. You fill in the About Me section in Session 2 and a link to each project after that. |
| `ridgeline/facts.md` | Everything Dr. Park told us about Ridgeline Veterinary Clinic. Every fact on a Ridgeline page must come from this file. |
| `ridgeline/hours.html` | Empty for now. You build Dr. Park's Hours and Prices page here in Session 4. |
| `.github/copilot-instructions.md` | House rules that GitHub Copilot reads before it answers you. |
| `.devcontainer/devcontainer.json` | Sets up your Codespace with GitHub Copilot and Live Preview. |

## Working rules

* Plan before you build.
* One small step per prompt.
* Check before you keep.
* Write a Check Note for every build: Prompt I used / What it did / What I checked / What I fixed.
* Use Ask mode for questions. Use Agent mode only to change files.
* Stop your Codespace when you leave.
